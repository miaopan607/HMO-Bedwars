# 云端训练港

Minecraft 1.8.8 独立虚空训练地图，默认世界名 `practice_shared`。主题采用石英甲板、深色橡木船底、青色玻璃导航灯。火球区橙色、搭路区青色、珍珠区紫色；地图内不放文字、告示牌或文字实体，操作与状态显示在菜单、动作栏及聊天中。

## 生成与导入

```bash
python3 tools/generate_practice_map.py
```

仅需 Python 3 标准库，默认交付目录为 `target/practice-shared/`：

- `practice_shared/`：包含 `level.dat` 和 Anvil 区域文件的世界目录。
- `practice.yml`：六个点位及两套八条搭路路线配置。
- `practice-shared.zip`：世界与配置的导入包。

通过 `--output <新目录>` 指定交付位置、`--world <世界名>` 指定世界目录名，生成器不覆盖已有交付目录。将世界复制到尚不存在的服务器世界目录；将配套配置的六个点位合并到 `plugins/HMO-Bedwars/practice.yml` 的 `points`，保留其他点位、用户修改、启用状态与 `npc`。不要覆盖已存在或已加载的世界。

安装支持目标训练与成绩输出的插件版本后，正常重启或执行 `/bw practice reload` 加载配置。插件从已有 `level.dat` 加载训练世界，不在运行时生成地图。更新插件 JAR 需要正常重启，不使用 Bukkit `/reload` 热换插件。

世界固定白天，关闭自然刷怪、火焰蔓延及随机刻；外围继续生成空气超平坦虚空。生成器按照 v1_8_R3 的实际遮光与发光参数统一传播天空光和方块光，包含跨区块、跨区块段及浮岛下方的光照。

## 布局与坐标

甲板最上层方块位于 Y=79，玩家站立高度 Y=80；平台厚三格，下方逐层收窄为浮岛船底。前方起跳区开放，后方及侧后方设置护栏和导航灯，飞行上空保持通畅。

六间沿 X 排列，同类房间完整复制。火球与珍珠每个点位支持多人共享，不设固定人数上限；新加入者优先进入人数较少的同类场地，已在同模式练习的玩家保留当前点位。搭路每间独占一人，同时容纳两人。

## 成绩口径

搭路与火球的用时使用单调时钟，以实际经过秒数计算，不依赖服务器 tick 数。聊天保留本次结果，动作栏立即显示成绩，然后恢复训练状态。落地依据脚底碰撞支撑面，支持整块、半砖和台阶；未完成的尝试不标记为成功。

| 模式 | 开始与结束 | 输出 |
|---|---|---|
| 搭路 | 首次成功放羊毛至站上目标平台；自由练习可到达任意目标 | 用时、水平直线位移、平均速度（位移÷秒数）、成功放块数 |
| 火球跳 | 首次有效火球推进至腾空后首次落地；接力推进沿用同一起点 | 相对首次推进脚部位置的最高腾空高度、落点水平直线距离、用时 |
| 末影珍珠 | 自由连续投掷 | 模式、状态与必要操作或边界提示 |

距离单位为格，速度为格/秒，小数保留两位。水平距离不累计绕行路线，火球高度不使用绝对海拔。失败、重试或主动退出时，活动中的搭路与火球尝试输出未完成结果；已结束的尝试不会重复输出。

## 操作与配置

`/bw practice` 打开模式菜单；火球与珍珠左右键均直接进入，搭路左键选择路线、右键自由搭路。快捷栏指南针再次打开菜单，箭头重试，床退出。模式和搭路路线可直接切换，场地不可用或传送取消时保留原会话。搭路满员可订阅空位通知，退出练习或离线取消订阅。共享场地重试和退出只清理本人的羊毛与投射物；玩家可以挡弹，火球只推进发射者。

训练默认免伤，菜单中的胸甲切换模拟实战伤害；火球推进算法与对局共用。玩家调整的训练物品槽位在同次会话的重试与模式切换中保留。训练物品会自动补充，三个控制物品保留固定槽位。

目标配置使用玩家脚部坐标。例如 `bridge-a` 的近、平、直路线：

```yaml
points:
  bridge-a:
    mode: bridge
    world: practice_shared
    spawn: '512.5,80,-11.5,0,0'
    pos1: '352,48,-24,0,0'
    pos2: '672,159,144,0,0'
    fail-y: 64
    enabled: true
    targets:
      target-1:
        name: '近·平·直'
        spawn: '372.5,80,10.5,0,0'
        pos1: '368,80,29,0,0'
        pos2: '376,81,37,0,0'
```

完整六点位配置由生成器输出。搭路目标 ID 在两间场地中保持一致，因此选择路线后可分配任一空闲搭路点位。`/bw practice join bridge target-1` 可直接选择近、平、直路线；火球和珍珠只接受模式，不接受目标参数。

管理员 `/bw practice list` 查看可加入场地数、练习人数、点位成员名单、禁用、世界缺失、出生安全及恢复状态。`/bw practice reload <id>` 单独重载一个空闲点；全量重载保留占用中的定义，错误点单独报告。共享点位最后一人退出后才能修改或重载。大厅入口通过 `/bw practice npc set` 在大厅内设置。

原玩家状态保存在 `practice-recovery/players/`，临时羊毛坐标保存在 `practice-recovery/blocks/`。启动时清理异常退出留下的已记录羊毛，玩家上线后恢复原物品与状态；相关区块落盘后才清除地形日志。恢复异常记录应保留以便排障。
